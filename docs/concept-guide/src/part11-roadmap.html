11.3 Test plan

Most of the bugs found so far (the flag-ordering race, contaminated keys, stale matrix reads, the keyframe-removal iterator) were caught by hand, after the fact. A small automated suite running Blender headless catches them before you open Blender:

blender -b tests/scenes/switch_basic.blend -P tests/run.py -- --case all
SceneAssertions
attach_roundtripAttach → Detach → Attach leaves the world matrix unchanged (±1e-5), with no rotation stacking.
arc_accuracyFor 20 factors, the add-on's predicted position = Blender's evaluated Follow Path position (±1 mm), including a cyclic curve and resolution 4.
switch_basicDiverge at frame 36: positions at frames 1/35/36/37/120 match stored golden values when scrubbed forward, backward and randomly.
switchbackMain → curve 2 → reverse onto curve 3. Every pivot and wagon is on the expected curve at each checkpoint.
yard_sidingsDead-end sidings ending close together never produce a switch (the §8.5 regression).
consist_spacingFour wagons through two switches: the gap between consecutive members along the route stays within ±5 mm.
render_parityWith nothing selected, a background render pose at frames 50 and 120 equals the viewport pose.
edit_invalidationMove a curve point after attaching: the next evaluation uses the new geometry.

11.6 Next five actions

  1. Write the v9 handoff and bump the version

    Record the consist prototype (not in v8), the missing Drag Pad, and this guide's audit list.

  2. Fix “active object only”

    Loop over every object with a Track It root in both handlers. This is the smallest change with the biggest effect (renders).

  3. Fix the arc cache

    Key it by curve.as_pointer() plus a geometry hash, and clear it in depsgraph_update_post for updated curve ids.

  4. Route pivots through _track_it_resolve_route_position

    This closes v8 §3.3 with code that already exists.

  5. Build the headless test harness

    Start with attach_roundtrip, arc_accuracy and render_parity, then refactor with confidence.

Closing note

The hard, fiddly parts are already solved: arc-length attach, crash-safe live driving, influence switching, junction-exact consist spacing. What's left is mostly moving decisions to where they belong (switches on the track, motion on the train, looks on the rig) and building the tools around them. The design sessions already pointed that way.
