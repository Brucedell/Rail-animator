Glossary

TermMeaning in this project
Track / curve / splineA Blender Curve object holding exactly one spline that a vehicle can ride. Follow Path only ever reads splines[0].
offset_factorThe Follow Path value (0–1, with use_fixed_location) that places an object along a curve. It equals distance ÷ curve length: it is arc-length based.
Arc tableThe add-on's 5,000-sample lookup of cumulative length vs world position, used to convert a world position into an offset_factor.
Held constraintA Follow Path constraint the object keeps for a curve it has been near. Influence 1 = driving, 0 = inert but kept (its keyframes stay intact).
Overlap zoneA stretch where two curves run on top of each other, so a vehicle can change curve without a visible pop.
Divergence pointWhere two overlapping curves separate. After it, switching between them is physically impossible.
JointEnd-to-end connection between two curves with no choice (one way on).
Turnout / junctionA real fork where a decision is needed. Proposed as its own object with a keyframeable state (Part 4).
Vehicle rootThe object the add-on actually drives along the track. The rig and mesh ride on it and are never bolted to it permanently.
PivotA point of the vehicle that tracks the rail on its own, such as a bogie, pony truck or trailing truck. Currently an auto-managed Empty with its own Follow Path.
ConsistA train: a lead vehicle plus coupled cars, each a vehicle with its own pivots.
Route distance / odometerThe running distance (metres) a vehicle has travelled along its actual route, across curve changes. The basis of the route-history log.
Live switchingChanging curves while dragging, with no keyframe written. Only at recorded forks or at a single unambiguous continuation.
Drag SliderThe spring-centred N-panel slider that nudges offset_factor. It is the primary live control; Mouse Drag is deprecated.
2-4-2Whyte notation: 2 leading wheels (1 axle), 4 driving wheels (2 axles), 2 trailing wheels (1 axle).
The rule every Part respects

Never create or write constraints on an object from a background handler while a 3D transform (TRANSFORM_OT_translate) is modal. This caused three identical crashes inside DEG_id_tag_update → recalcData_objects → transform_modal. It is why Mouse Drag is deprecated and why live control goes through N-panel widgets.
