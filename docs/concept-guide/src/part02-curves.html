2.1 What a curve object contains

A “curve” in Blender is three nested things. The object gives it a place in the world, the curve data holds the settings, and inside that is a list of splines, each a chain of points. Track It only cares about the first spline.

What each Bézier point stores

  • co: the point's position (in the curve's local space)
  • handle_left, handle_right: steer the shape either side
  • tilt: roll around the track direction. This is your superelevation
  • radius: scales bevel, and scales objects if “Curve Radius” is on (Track It leaves it off)

Bézier vs Poly/NURBS (“paths”)

A Path object (Add → Curve → Path) is a NURBS spline. It starts straight, which is why the switching tests used them. Its points have no handles; the shape comes from point weights. The add-on handles both: Bézier gets the cubic formula, the others are treated as straight lines between points, which is only an approximation for NURBS (Part 4).

2.2 How a Bézier segment is shaped

Between two neighbouring points, Blender draws a cubic Bézier. It starts at point A heading toward A's right handle, ends at point B arriving from B's left handle, and blends smoothly in between. A single number t runs from 0 at A to 1 at B:

position(t) = (1−t)³·A  +  3(1−t)²t·A.handle_right  +  3(1−t)t²·B.handle_left  +  t³·B

2.3 Parameter t vs real distance

This is the single most important idea for the whole system. Equal steps of t are not equal steps of distance. Where handles are long or points are bunched, t races ahead; elsewhere it crawls. In the segment above, t = 0.5 is only 46% of the way along.

Confirmed in the project

offset_factor = distance along the curve ÷ total curve length. Setting 0.25 puts the object a quarter of the way along in metres, whatever the handles look like. That is why an offset in metres converts to a factor with one division, metres / length, which is exactly what the pivot and consist code does.

2.6 Orientation, tilt and banking

With Follow Curve on, the constraint also rotates the object. At the object's point on the curve Blender builds a little coordinate frame: forward = the curve's direction there (the tangent), up = the curve's normal, then rolled by the point's tilt. The object's local +Y is aimed forward and its +Z up.

Watch out

On curves that climb or twist sharply, the “up” direction can flip or wander (Blender's twist_method: Minimum / Tangent / Z-Up). For railways, Z-Up is usually the calm choice, since track is mostly flat with gentle grades. Track Doctor (Part 4) should warn when it isn't set.

2.7 Why objects “jump” on attach

The early sessions fought this for a whole day (the “error 1–4” cones). The reason: with Follow Path active, the object's own location and rotation don't disappear. They are applied on top of the curve point, inside the curve's moving frame.

2.8 Direction, point order and extra splines

Two practical consequences: a curve's “forward” is set by how it was drawn, and joining two curves (Ctrl+J / F) can leave them facing opposite ways. The Track Network (Part 4) stores, for each connection, whether factor increases or decreases across it. Then direction never has to match.

Summary in one sentence

A track is a single spline. Follow Path turns a 0–1 distance fraction into a position and an orientation. Track It's whole job is to choose that fraction (Attach, Drag), choose which curve's fraction counts (influence switching), and derive the fractions of everything that rides along (pivots, wagons).
